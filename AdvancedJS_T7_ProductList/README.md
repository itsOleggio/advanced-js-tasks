# Задание 7.2 Изменение состояние каталога "Состояние компонентов"

## Описание 

Работа с состоянием компонента `Store`(Магазина), который добавляется в App, и за собой подтягиваем свои дочерний компонент `IconSwitch` который переддает 2 пропса `icon` какую иконку отображать и `onSwitch`- функция которая вызывается для изменения состояния. 

В компоненте `IconSwitch` находится текущее состояние `show` и его метод изменения `setShow` с изначальным состоянием `cardsта `. И два компонента для отображения в виде карточек `CardsView` или списоков `ListView`. 

Все компоненты реализовы с помощью функциональных компонентов. В ввиду использования современных технологий

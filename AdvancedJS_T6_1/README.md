# Задание 6.1 "React (Функциональный компонент)"

## Описание 

Пример использования функционального компонента в React. С использованием сборщика Vite.

## Код программы и структура проекта

Программа находится в папке `src`.

__Структура проекта__
```
advancedjs-t6-1/
├── index.html
├── package.json
├── vite.config.js
├── src/
│   ├── main.jsx
│   ├── App.jsx
│   ├── App.css
│   └── components/
│       └── ShopItemFunc.jsx
└── node_modules/
```

## Запуск программы

Сборка программы: `npm run build`
Запуск программы: `npm run dev`
Привью программы: `npm run preview`.

# Задание 6.3 "React (Функциональный компонент) - Календарь"

## Описание 

Пример использования функционального компонента в React. С использованием сборщика Vite. Пример создание календаря.

## Код программы и структура проекта

Программа находится в папке `src`.

Структура проекта 
```
advancedjs-t6-3/
├── public/
├── src/
│   ├── components/
│   │   └── Calendar/
│   │       ├── Calendar.jsx
│   │       └── Calendar.css (опционально, можно стили в App.css)
│   ├── App.jsx
│   ├── App.css
│   └── main.jsx
├── package.json
└── vite.config.js
```

## Запуск программы

Сборка программы: `npm run build`
Запуск программы: `npm run dev`
Привью программы: `npm run preview`
.
